One-line: the repeating prose + illustration unit that makes up most of a page body.

```jsx
<ContentBlock eyebrow="Blueprints" marker="task" title="Start from a working service"
  image="assets/illustrations/blueprint.jpg" action={{ label: "View blueprints", href: "/blueprints" }}>
  <p>Blueprints ship as Maven archetypes…</p>
</ContentBlock>
```

Alternate `reverse` on consecutive blocks so the page has rhythm. At most one action per block.
