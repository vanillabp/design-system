One-line: the uppercase gold label above a heading; pass `marker` to prefix it with a BPMN section glyph.

```jsx
<Eyebrow marker="start">Java SPI for BPMN engines</Eyebrow>
<Eyebrow>Runtime</Eyebrow>
```

Eyebrows are the one place a gold-toned *word* is allowed, and only in `--accent-text` (#806000, 5.85:1) — never `--brand-gold`.
