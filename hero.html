Java SPI for BPMN engines

Swap your workflow engine. Not your business code.

VanillaBP is an aspect-oriented service provider interface for business process engines. Your Java code talks to one abstraction. The adapter talks to Camunda 7, Camunda 8, or whatever you migrate to next.

Running on Camunda 7 — business code unchanged 

@Service
@WorkflowService(workflowAggregateClass = LoanApproval.class)
@Transactional(noRollbackFor = TaskException.class)
public class LoanApprovalWorkflow {

    @Autowired
    private ProcessService<LoanApproval> processService;

    @Autowired
    private LoanApprovalRepository loanApprovals;

    public void loanRequested(
            final String loanRequestId,
            final String customerId,
            final Float amount) {

        final var loanApproval = new LoanApproval();
        loanApproval.setLoanRequestId(loanRequestId);
        loanApproval.setCustomerId(customerId);
        loanApproval.setAmount(amount);
        // hand the DDD aggregate to the engine
    }
}
